# Abhay Prabhakar — Portfolio

Personal portfolio of Abhay Prabhakar: Founder's Office & Strategy.

Live: https://abhay-portfolio-12313.vercel.app/

## Stack
Plain HTML + CSS + a little JavaScript, bundled with [Vite](https://vitejs.dev/). Fonts are self-hosted via Fontsource (Instrument Serif, Geist, Geist Mono). Deployed on Vercel.

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build   # outputs to dist/
```

## Editing content
- All copy lives in `index.html`.
- Styles and colour tokens live in `src/style.css` (`:root`).
- Photos go in `public/images/` and are referenced from the `<figure class="ph">` slots in `index.html`.
- Résumé PDF: `public/Abhay_Prabhakar_Resume.pdf`.
